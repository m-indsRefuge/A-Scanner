# Roadmap

## V0.1 scaffold

- CLI and package
- Git clean guard
- Recursive uv/npm project detection
- Dependency inventories
- Native outdated checks
- Warning capture
- Compatible update commands
- Baseline and post-update validation
- Rollback
- Text and JSON reports
- Unit tests and CI

## V1 hardening

- Fixture repositories for uv, npm, and mixed projects
- Normalized uv `latest_compatible` and `latest_available` evidence
- Explicit direct/transitive ownership graphs
- Deprecation source attribution
- Timeout and cancellation policy
- Windows, Linux, and macOS acceptance matrix
- Schema validation and golden reports
- Packaged installation acceptance
- Public release review

## Post-V1

- More package-manager adapters
- Optional GitHub Action wrapper
- Optional MCP/tool interface
- LLM-assisted migration planning outside the deterministic core
